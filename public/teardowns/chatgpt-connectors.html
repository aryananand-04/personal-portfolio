02 — North Star Metric

The metric that
actually matters

Not session length. Not prompt count. The real value is task completion through connected tools.

North Star Metric
Weekly tasks completed via connected tools per active user
ChatGPT optimises for engagement — prompts sent, sessions opened. But connector success is measured by tasks that couldn't be done without the integration. A user who connects Gmail and completes 3 real workflows per week is worth 10x a user who opens the connector screen and never returns. Every product decision on connectors should move this number.

Apps are paywalled and invisible — zero access for 850M+ free users
ChatGPT has 900M weekly active users. App connectors require a paid plan — Plus, Team, Enterprise, or Edu. Free users have no access whatsoever. That means the connector ecosystem is structurally unavailable to the majority of ChatGPT's user base. On top of this, the app directory sits inside Settings, with no in-conversation discovery moment. Even paid users who have access rarely find it. The feature is simultaneously paywalled and buried — a double friction that keeps connector adoption low despite 60+ apps being available.

06 — Recommendations

Now / Next / Later
roadmap

Three initiatives, sequenced by impact and build complexity. Each with OKR-framed success metrics.

Now · 0–3 months
Surface connectors in the conversation flow
When a user's prompt implies a tool — "check my emails", "add to my calendar", "save this to Drive" — ChatGPT proactively suggests the relevant connector inline. One-tap connect. No settings navigation. The discovery moment happens at the point of intent, not inside a menu.
KR1 — Connector discovery rate: 3% → 25% of active users within 90 days
KR2 — 1-tap connect conversion: 40% of users who see the prompt complete setup
KR3 — Weekly connected task sessions: +3x in 60 days
Next · 3–9 months
Open the connector SDK — match Claude MCP
Release a public connector SDK for the 2 million OpenAI API developers. Let any developer build and publish a connector. Create a Connector Store inside ChatGPT with ratings, usage stats, and verification badges. This turns a closed 15-connector ecosystem into an open marketplace within 6 months.
KR1 — Third-party connectors published: 500+ in 6 months
KR2 — Enterprise connectors per account: avg 4 → 12
KR3 — Developer NPS on connector SDK: >45
Later · 9–18 months
Persistent workflow memory across sessions
Build connector workflow memory — ChatGPT remembers that every Monday you want a calendar summary, or that your Notion workspace is your primary notes destination. Workflows become persistent automations, not one-off requests. This shifts connector usage from episodic to habitual — the only metric that matters long term.
KR1 — Habitual connector users (weekly): 5% → 30% of enterprise seats
KR2 — Saved workflow templates created: 10M in 12 months
KR3 — Enterprise 12-month retention: 88% → 93%
07 — PM View

The bottom line

"ChatGPT has the users. Claude has the open ecosystem. OpenAI launched MCP — but gating write access to Enterprise only is the exact half-measure that loses the developer community."

900M weekly users is the most powerful distribution in AI — but connectors (now called apps) are paywalled for all free users. That's the majority of ChatGPT's user base locked out of the integration layer entirely.
OpenAI launched MCP support and an Apps SDK — the right move. But restricting write-capable connectors to Business/Enterprise while Claude offers full MCP access on all plans is a platform strategy error. Developers choose ecosystems, not individual features.
Apps are also disabled by default on Enterprise/Edu workspaces — admins must manually enable them. A feature that requires admin action to turn on will never reach its adoption potential. Default-on with opt-out is the only path to meaningful enterprise connector usage.
